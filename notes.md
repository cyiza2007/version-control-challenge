\# Git and GitHub Study Notes



\## What is Version Control?

Version control is a system that helps track changes made to files over time.



\## What is Git?

Git is a tool that tracks changes in your project locally.



\## What is GitHub?

GitHub is a website that stores Git repositories online for collaboration.



\## Basic Git Commands

\- git status

\- git add .

\- git commit -m "message"

\- git push origin main

\- git pull origin main

\- git checkout -b branch-name



\## Why Git is Important

Git helps developers collaborate and prevents losing work.
